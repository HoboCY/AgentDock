# 子代理任务的生命周期独立于窗口

AgentDock 的主面板和悬浮窗是配置、监控与控制入口，子代理任务由后台持续管理。关闭任一窗口不取消正在执行的任务；重新打开窗口连接并显示已有任务，停止任务与退出后台服务使用明确的独立操作。

用户完全退出 AgentDock 时，如果仍有未完成任务，先提示确认；确认后停止运行任务并取消排队任务。此操作与只关闭窗口的行为保持区分。

这一选择让用户可以在任务执行期间收起界面，也避免窗口重开触发已有任务重跑；代价是需要管理后台状态和重连行为。现有悬浮窗曾将自身的 Python 界面解释器沿启动链传给任务进程，造成执行失败，这也说明界面启动方式不应决定任务执行环境。

停止或超时只终止后续执行，保留任务已经产生的文件修改，并向 Codex 返回可以核实的变更信息；不自动回滚。这样避免回滚覆盖用户或其他执行者的并行修改，代价是需要由 Codex 根据实际变更决定后续处理。
