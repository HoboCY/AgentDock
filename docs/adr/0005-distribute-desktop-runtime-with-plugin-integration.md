# 安装包交付桌面运行环境与 Codex 插件接入

第一版通过 GitHub 分发 AgentDock 安装包和插件源；安装包负责桌面程序、所需运行环境和 Codex 插件接入引导，用户无需自行配置开发环境。

AgentDock 全新安装并独立配置凭据和角色，不提供既有 deepseek_agents 的迁移功能，也不接管或改动旧配置。用户在启用 AgentDock 前自行停用旧 MCP；发现新旧入口同时启用时，只提示可能重复派发任务。

桌面程序与执行引擎按经过验证的版本组合发布，只提示更新，由用户选择在没有未完成任务时应用更新。这用安装包体积和版本组合维护成本，换取普通用户更少的环境配置步骤，并避免独立更新执行引擎改变正在执行的任务行为；不将官方公共插件目录上架作为首版交付前提。
