## 验收发现并修复的路径错误

首个候选 `.20261020.1` 的插件已安装并启用，但引导无法进入下一步。Codex 返回 `/Users/hobo/projects/.../plugin`，界面保存 `/Users/hobo/Projects/.../plugin`。两者指向同一 APFS 目录，原 `CodexIntegration.SamePath` 在 Mac 上直接按大小写比较字符串，错误地报告插件属于其他安装。

两个最小 Mac 回归分别覆盖目录的大小写写法和符号链接，在修复前均失败。修复只将该比较改为现有 `ProjectPaths.Canonicalize` 与 `ProjectPaths.Comparison`，沿用文件系统的实际路径语义，避免把大小写敏感卷上的不同目录合并。修复后两项通过，并用重新构建的完整候选在全新目录重跑了原失败引导，结果通过。

测试和实现修改尚未提交/推送。首次 UI 失败、最小复现与修复后的结果分别保留。修复后首轮完整测试另遇到 VSTest `PortableSymbolReader.Dispose` 的关闭阶段空引用，尽管 96 个用例通过，该运行的退出码为 1，未计为完整通过；保留日志后使用相同已构建二进制复验，正常退出码 0，再继续打包。
