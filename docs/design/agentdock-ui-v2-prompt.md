Use case: ui-mockup
Asset type: high fidelity desktop application redesign reference, entire application window, 1440x1000 landscape.
Primary request: Redesign AgentDock, a Chinese native desktop monitor for coding subagents, as a refined, distinctive professional tool that can be faithfully implemented with Avalonia ShadUI. Design a finished interface, not a wireframe.
Composition: flat front-on screenshot fills the image, no laptop, no browser chrome, no perspective. Slim native titlebar. Dark charcoal left sidebar about 200 px; warm off-white main workspace; pale right task-inspector panel about 300 px. Main workspace is carefully aligned, readable, calm, dense enough for real work. Generous intentional spacing, fine dividers, understated rounded corners (8px), no gradients.
Sidebar: small geometric A brand mark and AgentDock wordmark; small subtitle "AGENT WORKSPACE"; navigation "任务" selected with muted teal background and simple outlined icon, "设置" below. At bottom a small green-dot "后台运行中" status, and quiet "显示悬浮窗" and "启动后台" actions. Sidebar dark #172323, text ivory.
Main top: small breadcrumb "工作空间 / 任务"; large heading "任务中心" with descriptive subtitle "每一次委派，进展尽在掌握。"; small outline "刷新" action upper right.
Stats: one compact horizontal strip with fine separators, labels "活跃任务", "输入 Token", "输出 Token", values "2", "128.4k", "16.8k"; small teal active dot, restrained typography.
Worklist: heading "全部任务" and small count; project selector on right "全部项目". A beautifully structured two-line list, NOT a traditional eight-column spreadsheet. Each row has small colored state icon, task title, tiny project and role below, and neatly aligned usage/elapsed on the right. Five sample rows: "重构任务工作台", "检查 IPC 连接状态", "验证 Windows 安装包", "整理角色配置", "更新使用文档". Statuses "运行中", "已完成", "等待中". First row selected with very pale teal fill and narrow teal left accent. Actual data are synthetic for this concept.
Right inspector: eyebrow "任务详情"; title "重构任务工作台"; teal pill "运行中"; project AgentDock; role worker; divider; two-column input/output tokens, speed and elapsed; understated task ID text; bottom fixed actions dark teal "查看结果", outline red "停止任务". Do not show a fake progress percentage or fake chart.
Bottom workspace subtle footer "任务由 Codex 派发 · 自动同步".
Style: elegant editorial typography using Segoe UI / Microsoft YaHei, crisp Chinese labels, monochrome icons, teal #267064 accent, warm white #F6F7F5, text charcoal #20312C, subtle #DEE5E0 borders. Real desktop proportions and readable typography; no giant cards, no excessive decoration.
Constraints: exactly two navigation destinations tasks/settings; no create-task button, no chat box, no avatar, no fabricated billing, no graphs, no photo illustration, no gradients, no purple. This is an implementation reference for an existing native app.
