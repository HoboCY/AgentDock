# AgentDock V1 运行契约

需求基线为 [Issue #1](https://github.com/HoboCY/AgentDock/issues/1) 与 ADR-0001–0005。

## 进程与接口

Desktop 只显示配置、摘要和结果；Host 持有任务状态；Engine 启动固定版本 OpenCode Go → DeepSeek。Codex 插件执行 Host 的 `--mcp` 模式，将 stdio MCP 请求代理至已有后台。窗口关闭或 MCP 连接断开不会调用停止接口。

后台使用按数据目录计算的命名管道和独占锁。管道限制为当前用户；不对局域网开放管理接口。请求使用单行 JSON；响应包含 `result` 或 `error:{code,message}`。每条消息最多 4 MiB，等待请求最长 45 秒。所有客户端使用相同数据目录连接唯一任务集合。

## 任务与恢复

请求身份为数据目录内全局唯一的 request_id（8–100 字符）；参数指纹包含规范化工作目录、角色、标题及正文。同身份不同参数拒绝。同身份相同参数返回原任务，包含成功、失败、中断、取消和已清理历史。

无自动重跑。运行中后台崩溃后标记 Interrupted；排队任务变为 Paused。Codex 可明确 resume 尚未执行的暂停任务；重做已经开始的任务须提供新的 request_id。

接收任务时持久化身份、角色提示词和时限快照；执行前持久化 Running，避免崩溃重启造成双重执行。状态文件以临时文件 flush + 原子替换写入，损坏时拒绝启动，不静默建立空任务集合。

默认全局并发 4，可设 1–32。default/worker/verifier 按项目协调写占用，父子目录也冲突；explorer/reviewer 不占写锁。路径必须为现有绝对目录，路径及其父目录的符号链接/联接拒绝，避免别名绕过锁。实际执行仍在指定目录，不自动建 worktree。调度只协调 AgentDock 自身任务，Codex 主代理负责其他执行者的文件归属。

停止运行任务先触发进程终止，待引擎结束后公布终态；停止排队或暂停任务直接取消。完全退出存在未完成任务时需 confirm；退出流程停止接收新任务并取消所有未完成任务。取消不回滚文件。

## 用量和保留

提供方上报的生成阶段使用独立事件身份；重复事件不累计，分批修订覆盖该阶段旧值。尚未报告的输入或输出为 null。输出包含推理 Token，提供方字段解释由执行契约固定。可靠生成时长缺失时速度为 null，不以任务总耗时替代。

总耗时从 AcceptedAt 起算，终态截止 FinishedAt。摘要与正文均从 FinishedAt 起算，分别保留 30 天和 7 天，达到边界即可清理。运行、排队、暂停状态不受终态清理影响。正文到期返回 bodyState=expired；摘要清理返回 SummaryExpired。手动清理支持正文或全部终态历史，并先预览数量。请求墓碑永久保留最小身份、指纹、终态，防止历史清理重新执行旧请求；墓碑不保留任务正文。

详细事件每条截断至 16000 字符，最近 2000 条保留；最终结果独立保存。消费者使用 nextCursor 分页并 drain hasMore。旧事件超出缓冲时游标可以前跳；接口不将它们伪装成完整审计日志。

## 验证边界

自动化测试验证协议、调度、持久化与恢复。真实桌面、实际 Codex 插件调用、OS 沙箱拒绝及干净安装均有各自验收证据，互不替代。macOS 没有实机证据时不得声称支持；Windows 不因此虚报跨平台验收。
